## How to Add Images

1. Search Wikimedia Commons for suitable images
2. Download images at ~1600px width
3. Compress to under 300KB using JPEG or WebP
4. Save to /images directory with the filename above
5. Update the credit line in story.md with: "Photo by [Author], [License], [Source URL]"
6. Update this file with proper attribution
